# Первые экраны сайта

React + Vite + strict TypeScript. Реализованы общая оболочка, первые части «Обзора», «Операций», «Анализатора» и «Настроек»: пустой вход, явно включаемый пример, глобальные фильтры, четыре показателя, категории, динамика расходов, крупнейшие расходы и окна с объяснениями/операциями.

Пример содержит 18 вымышленных операций сентября 2026 года. Он загружается только после нажатия «Посмотреть пример», хранится в памяти и исчезает после перезагрузки. Нет записи в аккаунт, localStorage, базу, API или AI. Денежные суммы представлены строками целых копеек; расчёты используют bigint, включая возвраты и отрицательные net расходы.

## Запуск из корня репозитория

Требуются Node.js 24 и pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm run dev:web
```

Открыть http://127.0.0.1:5173 и нажать «Посмотреть пример».

```sh
pnpm run check
pnpm --filter @finance/web exec playwright install chromium --only-shell
pnpm run test:e2e
```

Установленный Chromium можно указать через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. CI использует обычный браузер Playwright. Мобильные проверки выполняются в Chromium с параметрами iPhone 13; это не проверка Safari или настоящего iPhone.

## Граница реализации

«Обзор» и «Операции» доступны через навигацию. Нажатие графика открывает Операции с контекстом. Есть поиск, быстрые/дополнительные фильтры, сортировка, выбор записей и карточка для чтения. В Анализаторе есть отдельные диалоги, поиск/закрепление/переименование/удаление, четыре демонстрационных вопроса, объяснение расчёта и переход к операциям. AI не подключён; произвольные вопросы не обрабатываются. Чаты и черновики остаются в памяти, при закрытии примера или перезагрузке исчезают. В Настройках доступны десять разделов, поиск, тема/плотность/размер текста/уменьшение движения, безопасный сброс оформления и переходы к операциям счёта/исключениям. Финансовые параметры доступны для просмотра. Оформление существует только до перезагрузки. Загрузка, профиль, исправления и сохранение пока недоступны. Графики первого экрана — простые полосы с точными текстовыми суммами; полноценный каталог графиков на ECharts, сравнения, бюджеты, сохранённые представления и настраиваемые виджеты предстоят.

`src/demo/overview.ts` — проекция искусственных данных для проверки интерфейса, а не самостоятельный финансовый движок. Серверное общее ядро, связанные возвраты/компенсации, части, классификация, история, права и реальные данные не реализованы этим шагом. Полные требования PDF продолжают действовать.

## Загрузка и профиль

Окно загрузки открывается из шапки всех экранов, пустого Обзора/Операций и Настроек → Загрузки. Оно хранит только локальные метаданные выбранных файлов; bytes не читаются и не отправляются. Повторные выборы не объединяются. Закрытие очищает список. Профиль показывает неподключённые аккаунт/безопасность/доступ, временный черновик поддержки и рабочую смену темы. Переходы к общей истории и истории выбранной операции не создают записи и сохраняют финансовые фильтры/диалоги. Проверки: `e2e/shell.spec.ts`.
