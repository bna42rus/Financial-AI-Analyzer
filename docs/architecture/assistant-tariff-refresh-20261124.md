# Автоматическая проверка тарифа Анализатора

Основание: PDF §28–29 и запрос владельца 24.11.2026 автоматически проверять
обновлённые тарифы и считать новые обращения по подтверждённым новым ценам.

Прежняя проверка всей контрольной суммы PDF блокировала месячный Staging после
публикации Cloud.ru версии 261121 вместо 261029. Проверено 24.11.2026: собственные
SKU gpt-oss-120b (строки 271/272) по-прежнему стоят 15.86/61 RUB за миллион
входных/выходных токенов с НДС. Другая, партнёрская OpenAI SKU намеренно исключена.

## Новый контракт

- Источник фиксирован: HTTPS PDF Cloud.ru current-version/foundation-models.pdf.
  GET без ключа приложения и без перенаправлений, не более 2 МБ, timeout 15 сек.
- Перед каждым платным monthly dispatch выполняется условный GET. ETag/304
  позволяет повторно использовать только ранее разобранные цены; параллельные
  обращения разделяют выполняющуюся проверку. Ошибка не разрешает stale fallback.
- pdftotext извлекает текст из pipe без файлов и наследования секретов приложения.
  prlimit ограничивает процесс: 512 МБ адресного пространства, 5 секунд CPU,
  10 секунд wall clock и 2 МБ stdout. Нужны poppler-utils и util-linux на сервере.
- Выбираются ровно две собственные SKU модели с единицей «млн шт», месячным
  периодом и рублёвыми колонками. Проверяется равенство цены без НДС + НДС цене
  с НДС. Деньги разбираются десятичными строками/BigInt, без float.
- Изменение соседних строк/номеров/общего hash не блокирует работу. Однозначные
  новые положительные ставки проходят существующий tokenPrice validator и
  становятся ценой новых monthly reservations до HTTP POST. Модель/провайдер,
  бюджет 100 RUB, RLS и бюджетные locks остаются прежними.
- reserveCost сохраняет цену в конкретном резерве; settleCost использует эту
  сохранённую цену. Завершённые расходы и старые резервы не переоцениваются.
- При недоступном источнике, дубликатах строк, неподдержанной валюте/единице,
  некорректной цене или невозможности извлечь текст запрос не отправляется.
  Произвольные новые правила биллинга автоматически не интерпретируются.
- Legacy короткие trial admissions сохраняют согласованные ставки и потолки;
  изменение их ставки по-прежнему требует отдельного допуска. Автоматическое
  обновление относится к уже разрешённому monthly Staging, не включает Production.

## Выкладка и проверки

Ветка основана на реально запущенном ec7367d, чтобы обновление не включало
другие ещё не выложенные изменения transport/workflow/accounting. Перед сменой
релиза новый код проверяет реальный публичный PDF; затем существующий updater
создаёт S3 predeploy backup и сохраняет rollback. --preserve-active-ai меняет
только привязку исходников действующего допуска, не сбрасывает ключи/расходы.

Тесты проверяют PDF с изменившимися байтами, одинаковыми/новыми ценами, ETag,
неоднозначность, единицы и НДС. Генерируемый синтетический PDF проходит настоящий
pdftotext и staging provider: следующая резервация видит новые ставки, история
и конфигурация сохраняются, ошибочный документ не приводит к POST.
