# Компактные общие фильтры — 29 октября 2026

По запросу владельца убраны вводная подпись под заголовком экрана, пояснение о множественном выборе/серверных итогах и повторяющиеся оговорки про банковский баланс. Формулы и правила денег не меняются: PDF §§4.5 и 21.1 остаются действующими; изменение касается представления.

Общие фильтры для подключённых Обзора, Операций и Анализатора используют один компонент. В свёрнутом виде это строка фиксированной высоты: категории, две даты, банк, счёт, «Сбросить», стрелка подробностей. На узком экране поля прокручиваются внутри строки, не расширяя страницу. Длинные значения ограничены шириной поля; для нескольких категорий подпись «Выбрано несколько».

Категории открываются в меню с поиском, галочками, вложенными подкатегориями и собственным сбросом. Выбор одного пункта не требует специальных клавиш. Поиск по ребёнку сохраняет родителя для контекста; поиск не сбрасывает отмеченные пункты. Родительская галочка означает всю категорию с подкатегориями — существующая серверная семантика parent ID. Включённые родителем дети показаны отмеченными и недоступны для отдельного снятия, пока выбран родитель; произвольную часть дерева выбирают отдельными дочерними галочками. Это не имитация исключения дочерней категории, которого в текущем wire-контракте нет.

Сброс в меню очищает только категории и строку поиска. Общий «Сбросить» возвращает всю историю, все банки/счета и все категории, как прежняя кнопка «За всю историю». Стрелка справа раскрывает полные условия с названиями выбранных категорий и подкатегорий. Скрытые выбранные/недоступные категории можно снять; они не удаляются из фильтра молча.

Меню поддерживает focus search, Tab, Escape, закрытие снаружи и возврат фокуса. В режиме заблокированного изменения недоступны также вынесенные в portal элементы. Исправлено влияние невидимых подписей на layout viewport мобильного браузера; проверяется не только отсутствие scroll overflow, но и соответствие viewport ширине устройства.

Проверки: TypeScript и 93 web unit; шесть адресных desktop/mobile сценариев; 138 успешных browser сценариев Обзора/Операций/Анализатора на desktop/mobile. Отдельно проверяются точные category IDs в серверном запросе и отсутствие финансовых preview/commit при работе с фильтром.
