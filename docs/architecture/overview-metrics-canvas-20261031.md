# Обзор — согласованный план 31.10.2026

1. Метрики: закрытый полный перечень без произвольного предела трёх; деньги/операции на разных шкалах или графиках. Бюджет — план/факт/остаток/превышение/процент в собственной области каждого бюджета, без суммирования пересечений. Совместимость сохранённого JSON.
2. Полотно: свободные координаты компьютера, без обмена местами и наложений; адаптивное число карточек в строке. На телефоне отдельный порядок без изменения размеров. Добавление снизу.
3. Редактор: имя, метрики, группировка сверху, затем только применимые настройки графика/периода/сравнения. Без поиска метрик; список помещается в окно. Цифровой ввод 1–50, ноль нельзя применить. Для времени нет кольца. Настраиваемые подписи над графиком.
4. Периоды: профильный календарь, нулевые интервалы, явное сопоставление равных/календарных периодов; разные длины не выравнивать молча по индексу. Точные даты сравнения доступны пользователю.
5. Локальные условия: единое дерево категорий/подкатегорий, банк/счета/период/поиск с явным наследованием. Без громоздких дополнительных фильтров и отдельного скрытия категорий. Старые сложные условия не терять незаметно.
6. Общие фильтры не создают баннер сохранения представления. Закрытие изменённого редактора — центральное подтверждение с применением/отменой/продолжением. Footer с реальными сведениями.
7. Управление представлениями обсуждается отдельно; существующие данные и возможности не удалять. Desktop/mobile независимы.
8. Проверки: целые копейки, сочетания метрик, бюджеты, интервалы/сравнения, совместимость JSON, отсутствие коллизий, браузеры desktop/mobile, типы и connected-сборка. Платных вызовов/изменения допуска ИИ нет.

Явные уточнения владельца заменяют прежние ограничения в PDF (три метрики, budget отдельно, фиксированная сетка). Банковские факты, ownership, закрытые контракты, preview/commit/Undo сохраняются. Реализация начата; установка новой работы не заявляется.
