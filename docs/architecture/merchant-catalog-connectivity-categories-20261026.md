## Основания и предлагаемые категории

Прочитаны PDF v1.3, разделы 13–14 и 16–17, source manifest и starter.ts. Действующее дерево: «Связь и интернет → Мобильная связь / Домашний интернет / Прочая связь»; категории полностью принадлежат пользователю. «Аренда пауэрбанков» уже выбрана в отдельном разделе для будущего добавления, но в этом шаге не создаётся. Личные категории/подтверждения/правила имеют принятый приоритет. Профиль не меняет надёжные банковские факты и финансовый вид операции.

Все строки ниже условны: установлена подходящая оплата, профиль получателя/услуги достаточно надёжен, нет PEND для автоматического узнавания, конфликтов или более приоритетного пользовательского решения. Не требуется знать полный состав тарифа для очевидного направления; отсутствие расшифровки само по себе не вызывает «Стоит проверить».

| Достоверно установленное назначение | Предложенное размещение | Когда нужна проверка категории |
|---|---|---|
| Мобильный тариф, минуты/SMS/мобильный интернет, включая банковские MVNO и региональные бренды | Связь и интернет → Мобильная связь | Не из-за отсутствия чека. Имя банка без мобильного сервиса не устанавливает это назначение |
| Домашний доступ в интернет у NET018–024, NET028–042, либо услуга NET025–027 | Связь и интернет → Домашний интернет | Не из-за отсутствия адреса/номера договора. Известное иное назначение приоритетнее |
| Очевидный домашний интернет-провайдер при обычном абонентском платеже | Домашний интернет без обязательного Review | Возможность продажи роутера/ТВ сама по себе не делает каждый абонентский платёж неоднозначным |
| Установлен телеком-платёж, но действительно неизвестно: мобильная/домашняя/другая связь | Предварительно родитель Связь и интернет + Стоит проверить | Не выбирать случайную дочернюю категорию. Причина: оператор оказывает несколько видов связи |
| Известен единый пакет мобильная+домашняя связь+ТВ без достоверных отдельных сумм | Своё правило пользователя; иначе предварительно Связь и интернет + Стоит проверить | Не выдумывать преобладающую долю по рекламе и не создавать части без сумм |
| Отдельная доказанная подписка Wink/КИОН/ТВ-пакет Триколор, НТВ-Плюс, Телекарта | Подписки и цифровые сервисы → Видео и музыка | Не приписывать все списания Ростелекома/МТС кинотеатру. Оборудование не подписка |
| Частная фиксированная телефония или личная IP-телефония | Связь и интернет → Прочая связь | Корпоративный имидж NET039/NET043–048 не доказывает работу пользователя |
| Подтверждённая рабочая АТС, телефония, связь для бизнеса | Работа и бизнес → Сервисы для работы либо подходящая личная категория | Имя MANGO OFFICE/UIS/Телфин/Zadarma/Sipuni/МТТ без цели само по себе не бизнес-расход |
| Известный тариф SaaS/CRM или цифровая услуга | ПО и приложения либо Сервисы для работы по личной/рабочей цели | Не телефонный тариф только из-за общего поставщика; уточнить цель, если она меняет категорию |
| Покупка/аренда/ремонт оборудования, SIM как физический носитель, установка | По фактическому предмету/услуге и имеющемуся дереву | Не назначать всему Домашний интернет; общий профиль оборудования не доказывает категорию Товары для дома. При отсутствии подходящего узла не создавать его молча |

## Что остаётся согласовать и проверить позже

На согласование: предложенный широкий родитель для действительно неясного вида связи/комплексного пакета; категории отдельных ТВ-подписок и рабочей телефонии; сама таблица NET-U01–U20. Новые категории здесь не предлагаются. Не подтверждённые источники, исторические контуры, произношения и PEND обоих перечней остаются открытыми, а не превращаются в PASS из-за появления этого документа.

После решения владельца подготовить отдельный набор положительных/отрицательных/неоднозначных/конфликтных сценариев с видимыми синтетическими входами и ожидаемыми результатами; фактический результат появится только при будущей реализации/исполнении. На текущем шаге проверяется только целостность и форматирование документа. Сайт, API, БД, миграции, модельные настройки и оплачиваемые вызовы не менялись.
