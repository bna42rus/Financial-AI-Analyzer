# Сверка голосовых требований с реализацией — 24.10.2026

Основание: голосовые решения владельца 24.10 и код PR #50. Это аудит полноты, а не утверждение, что все требования приняты. Базовый релиз: 27692dbdbcbdf639cd66589ddf652557580de650.

## Сделано в коде, требуется проверка на следующих выписках

- Банковское описание отдельно от имени; известные бренды получают короткое имя, сохранены значимые цифры. Для неизвестных нет универсального корректного перевода на русский.
- Продуктовые сети, включая Магнолию/SPAR, и явная доставка известного продуктового магазина; общий магазин одинаковый для доставки и покупки в магазине. Обычное слово «доставка» не доказывает продукты.
- Аптека, кафе/столовая, фитнес и другие признаки деятельности с ограниченным набором транслитераций; осторожное сопоставление искажений длинных слов.
- Маковка/Буханка — общепит; DDX — фитнес; Мостранспорт не означает автоматически метро или автобус.
- Вендинг — продукты/прочие продукты с Review, оператор без уточнения услуги — связь с Review.
- Каршеринг и пауэрбанки распознаются; для пауэрбанков нет согласованной персональной категории, текущий fallback — прочие расходы с Review, это требует проверки владельца.
- Маркетплейсы используют одноимённую категорию при наличии, иначе прочие расходы; конкретный товар не угадывается. Общий Яндекс остаётся неопределённым.
- Личные правила и подтверждённые фасеты защищены. Разовая правка не попадает автоматически в общий каталог и не создаёт личное правило.
- Номера «с договора»/«по договору» скрываются, повторная очистка выдачи старых /4 описаний. Это не полная физическая очистка всех исторических таблиц.

## Частично или не сделано

1. Полный полезный справочник Москвы и крупных сетей России не собран: 64 записи — начальная выборка. Санкт-Петербург не имеет отдельного детального режима.
2. Словарь синонимов/сокращений/банковских написаний для всех подходящих категорий не завершён. Есть стартовый набор, без измеренной полноты.
3. Переименованные и произвольные категории пользователя учитываются моделью и частью точных правил, но не существует полного проверенного смыслового соответствия любого пользовательского каталога.
4. В карточке исправления нет единого диалога «только эта операция / запомнить для похожих». Есть отдельный редактор правила и узкий распознаватель явных команд в Анализаторе.
5. Команды правил понимают ограниченный шаблон («весь/все ... относить/относи к/в ...»), а не произвольный естественный язык. Сначала категоризатор; полноценный Анализатор — отдельное продолжение.
6. Подтверждение конкретного получателя перевода с устойчивым HMAC и автоматическое последующее сопоставление не закончено. Оно ранее оставлено в плане; HMAC полного описания не заменяет отдельную идентификацию получателя.
7. В каталоге отсутствуют полноценные поля даты проверки/уровня достоверности источника, границ неоднозначности и подтверждённых банковских алиасов. URL сам по себе не является полной проверкой записи.
8. confidence 75/80/95/96 — уровни правил и маршрутизации Review, а не измеренная вероятность правильного назначения. Нужен контроль ошибок и пропусков на расширенном синтетическом корпусе и следующих выписках.
9. Нет полной приёмки на других годах/банках/форматах; проверки текущей выборки этого не заменяют.

## Ошибки, найденные при этой сверке

- «Магнит Косметик» в исходных 64 записях ошибочно распознавался как обычный «Магнит» → продукты (96). Добавлено отдельное проверенное направление «М.Косметик» и явное предпочтение дочернего бренда родительскому. Случайные сочетания независимых брендов по-прежнему конфликтуют.
- «Ветклиника Север» ошибочно попадала в «Питомцы → Корм и товары» (95). Ветеринарные услуги отделены от зоомагазина, используют «Ветеринар», а при отсутствии подкатегории оставляют только родителя.

После этих исправлений в каталоге 65 записей. Это исправление ошибочного различения брендов, не выполнение задачи масштабного расширения.

## Дальнейшее расширение

Сначала аудит всех 65 записей и отрицательные примеры (похожий бренд, другое направление бренда, посредник, разные услуги). Затем пополнение по категории: продукты/доставка; общепит; аптеки/медицина/фитнес; транспорт/каршеринг/парковки/прокат; операторы/интернет/цифровые сервисы; дом/ремонт/бытовые услуги; одежда/красота; развлечения/книги/образование; питомцы; путешествия. Москва — подробный охват, остальные регионы — крупные сети.

Для каждой новой записи нужны публичный источник, дата проверки, вид деятельности, canonical display name, подтверждённые либо явно нормализованные формы написания, неоднозначности, положительный и отрицательный пример. Слово «Москва» в банковском хвосте не служит географическим доказательством магазина. Доходы, личные переводы, кредиты, налоги и подарки не выводятся из названия продавца.

Пример личного правила: «Весь вендинг относить к продуктам» означает явное решение конкретного пользователя для его будущих подходящих расходных операций. Оно открывает редактор существующего механизма правил; до сохранения изменений нет. Это не автоматически заданное правило для всех пользователей и не требование вводить точную фразу для обычной категоризации вендинга.
