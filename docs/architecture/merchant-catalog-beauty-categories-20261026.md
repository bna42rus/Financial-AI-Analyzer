# Красота и уход: назначения BEA001–BEA056 и правила BEA-U01–BEA-U28

**Статус:** проект на согласование владельцу, 26.10.2026. Это **дополнение к [единому справочнику](./merchant-catalog-master-20261025.md)** (записи BEA001–BEA056) в рабочей ветке PR №53. Отдельный файл выбран потому, что большой мастер-файл перестал корректно возвращаться для безопасного редактирования. Перед реализацией интегрировать правила по стабильным BEA ID, без дублирования.

**Существующие категории:** «Красота и уход → Парикмахерские и салоны», «Косметика и уход», «Прочий уход». Пограничные: «Здоровье и спорт → Врачи», «Образование → Курсы», «Работа и бизнес → Сервисы для работы/Реклама», «Подарки и благотворительность → Подарки», «Жильё и дом → Товары для дома». Это стартовое дерево, не принудительное для пользователей со своими категориями. **Не создавать категории автоматически.**

**Важные инварианты:** доказанный фактический получатель ≠ производитель товара ≠ агрегатор записи; экономическая цель оплаты и финансовая роль проверяются отдельно. Для очевидного обычного профиля специализированного магазина/салона отсутствующий чек **не** создаёт «Стоит проверить». При настоящей неоднозначности допустим обоснованный предварительный профиль + видимый Review; если нет оснований даже для направления — не назначать наугад. Все банковские факты, исходная строка, source/HMAC, дата/сумма/валюта, userVerified, личные правила, split/dedupe и разграничение пользователей неизменны. Нельзя выводить здоровье, диагноз, пол или личные процедуры только из бренда.

| BEA-U28 | Повторный импорт, HMAC, чужой пользователь, cache и ответы модели | Неприкосновенны source/provenance, роли, суммы, dedupe, идентичность и доступ. Не восстанавливать телефон/ФИО или медицинские факты из HMAC, не считать высокий confidence разрешением. |

## Решения, предложенные на согласование

1. Золотое Яблоко, Лэтуаль, Рив Гош, «Магнит Косметик» и «Улыбка радуги» — обычная категория «Косметика и уход» без лишней пометки за отсутствие чека; доказанный бытовой/детский товар уточняет категорию. Разрешение многопрофильных конфликтов остаётся независимым.
2. Парикмахерские, барбершопы, маникюрные студии — «Парикмахерские и салоны» без Review для очевидной услуги. Подтверждённый курс/товар/франшиза отдельно.
3. Явно эстетическая эпиляция → «Прочий уход», медицинская консультация — только при доказанном виде врачебной услуги. Wax & Go многосервисный; категория может быть предварительной с «Стоит проверить» лишь когда действительно неясно направление.
4. DIKIDI и YCLIENTS — межраздельные платформы записи/CRM, **не** салон/маникюр по названию. Оплата услуги и рабочая подписка не смешиваются.
5. Косметический бренд на упаковке не равен получателю денег, PEND не активировать до доказательств; «Белорусская косметика» — не отдельный merchant.
