# Обзор и отправка вопроса: согласованные изменения 2 ноября 2026

Основание: правки владельца в текущем диалоге (10 пунктов), поверх PDF 21.3–21.6.

- Незавершённый запрос можно продолжить кнопкой отправки с тем же request ID.
  До подтверждения доставки новый платный запрос автоматически не создаётся.
  Завершённая задача убирается из локального pending; после смены runtime
  устаревшую задачу можно отменить без удаления квитанций.
- Уведомления остаются вверху справа, в том числе при открытом диалоге.
  Portal сохраняется внутри активной modal focus scope для клавиатуры и Undo.
- Встроенное представление имеет меню копирования и выбора по умолчанию.
  Выбор встроенного по умолчанию хранится существующим обратимым действием
  save_overview_view с постоянным ID; в меню не появляется вторая строка.
  Переименование/удаление встроенного не предлагаются. Меню не двигает троеточие.
- Сохранить / Сохранить как новое / Сбросить — отдельные кнопки над виджетами.
- Desktop: автоматические две колонки, половина или вся ширина, одинаковый
  отступ 16px, высота 240–1600px. Старые свободные координаты не фиксируют
  карточки. Перетаскивание меняет порядок; соседние карточки анимированно
  перераспределяются. Mobile сохраняет независимый порядок, без resize.
  Раскрытие значений временно увеличивает высоту и сдвигает соседей.
- Отдельные переводы-поступления/списания и наличные-внесения/снятия —
  положительные величины; прежние разности остаются отдельными метриками.
  Платежи по кредиту — все списания; тело — только известные principal-компоненты;
  расходы на кредит — проценты, комиссии, страховка. Неизвестное тело не выдумывается.
  В редакторе возвраты/компенсации объединены; прежние записи читаются.
- Стандартные виджеты сбрасываются к своей исходной конфигурации. Копия
  стандартного виджета сохраняет templateId, но собственный id не меняется.
- Бюджетная процентная ось размечается в процентах от 0 до 100% (выше при
  превышении); проценты не смешиваются с денежной шкалой.
- Фиксированные даты находятся под своим селектором: текущий период слева,
  сравниваемый справа; на телефоне колонки идут последовательно.
- Группировка «Время»: интервалы сравниваются по порядку внутри каждого периода.
  Сравниваемые недели отсчитываются семидневными отрезками от начала каждого
  периода. Явно выбранный месяц не обрезается последней имеющейся операцией;
  безграничная история и существенно более широкий диапазон используют границы выписки.
  Разная длина месяцев/недель не обрезает более длинную сторону. Отсутствующие
  интервалы графика имеют 0, при этом реальные границы второго периода остаются
  в previousFilter. Drilldown отсутствующей текущей части явно пустой.
  Итоги по-прежнему считают каждый период целиком, независимо от числа точек.

Проверки: точные суммы и drilldown новых метрик, разные длины месяцев,
разные начала недель, нули в рядах, сетка/расширение, меню/default/Undo,
продолжение того же request ID. Все данные синтетические, без модельных POST.

Дополнение владельца (11–14): единый выбор банков/счетов деревом с поиском
используется в общих и локальных фильтрах. Выбор банка равен выбору его счетов;
любой счёт можно снять независимо. Множественный выбор передаётся серверу
через accountIds во всех трёх экранах, не теряется при drilldown/смене экрана.
Под локальными фильтрами показана компактная сводка собственных ограничений.
Последнюю включённую видимость desktop/mobile нельзя снять. Подпись текущего
периода выводится один раз; второй блок явно обозначает период сравнения и
его показатели. Кнопки редактора собраны внизу: удаление слева, сброс/исходные
настройки в центре, копия/применение справа; закрытие — крестик сверху справа.
