# CashNeuro: оформление и знак

Основание — прямое поручение владельца сменить медицинскую ассоциацию зелёного оформления и самостоятельно выбрать вариант.

| Вариант | Ассоциация и применение | Решение |
|---|---|---|
| Графит + индиго + светлая бумага | Строгие финансовые таблицы, спокойный фон, индиго для AI и действий | Выбран |
| Тёмный синий + янтарное золото | Финансы; AI менее выражен, жёлтый конкурирует с предупреждениями | Рассмотрен |
| Синий + бирюзовый | Данные и технологии; сохраняет нежелательную медицинскую ассоциацию | Рассмотрен |

Светлая тема: действия `#5145D8`, текст `#1B2440`, фон `#F5F6FB`. Тёмная: фон `#101320`, панели `#191E30`, действия `#B4AEFF`. Состояния различаются также текстом и значком; график сохраняет таблицу. Контраст проверяется вычислением sRGB. Тема, плотность, крупный текст и Reduced Motion сохраняются.

Рассмотрены три знака: монограмма CN, монета с нейронными связями и связанная траектория внутри открытой C. Выбрана траектория: C от CashNeuro, движение финансовых данных и две точки связи. Без медицинского креста и мелких деталей.

Три native SVG: `apps/web/public/brand/cashneuro-favicon.svg`, `cashneuro-symbol.svg`, `cashneuro-logo.svg`. Компонент Brand использует те же контуры. Название CashNeuro: Cash — основной цвет текста, Neuro — индиго; плотный читаемый интервал. Локальный системный sans-serif стек, без загрузки стороннего шрифта/трекеров. Контуры знака созданы для этого репозитория.

Функции и финансовые данные сохраняются. Подтверждения оформляются отдельным диалогом, подробные настройки раскрываются по запросу.
