# Правки Обзора и Операций от 3 ноября

Владелец уточнил §21.8, §23.9 и §24 исходной спецификации: глобальные фильтры не сохраняются в представлениях Операций; дополнительные условия можно сохранять отдельно. Карточка сохраняет локальный черновик по кнопке, затем показывает предварительный расчёт для подтверждения. Исходные банковские факты, подтверждение связей, права доступа и история изменений остаются в прежнем контуре.

- При первом копировании встроенного представления исходный набор и копия сохраняются атомарно. При удалении активного значения по умолчанию назначается другой набор; отмена восстанавливает оба изменения.
- Поиск в общих и дополнительных фильтрах: `&` (и) имеет приоритет над `|` (или). Причина проверки берётся из фактических признаков операции; множественные фильтры типа, смысла и классификации применяются на сервере.
- Ширина и порядок колонок, группировка, сортировка и число строк относятся к виду списка. Общий фильтр не изменяется при переключении вида.
- Подтверждение карточки и массовой правки использует существующие preview/commit и проверку ревизии. Маски реквизитов заменяются на пять звёздочек только при отображении.

Проверено локально: 98 тестов расчётов, фильтров, Обзора и имён операций; типы API и Web. PostgreSQL и браузерные проверки входят в CI.

Следующее уточнение владельца (§23.1, §23.10–11, §24.3–8): быстрый ряд заменён переключателем «Показать требующие внимания». Действия и переходы в Операции меняют указанные ими условия, остальные фильтры сохраняются. Правый клик открывает копирование ID, историю и удаление. Окно массовой правки не входит в этот блок.

Банковские значения, состав и связи редактируются в отдельных окнах. «Применить» меняет черновик карточки; один подтверждённый запрос сохраняет все изменения в одной транзакции. Необратимое удаление имеет отдельный предпросмотр состава. Ошибку, которую можно отнести к конкретному полю, показываем под этим полем и отмечаем его границу, а общую ошибку показываем отдельно.
