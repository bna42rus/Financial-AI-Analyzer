# Первая версия Анализатора

4 октября 2026 года. Следующий экран после принятых Обзора и Операций; основа 1.3 не изменена. Операции приняты и объединены через [PR #3](https://github.com/bna42rus/Financial-AI-Analyzer/pull/3), commit 51c2bf8b2cd8f2bea8acfd3756d0dcd581d51b9e.

## Что можно проверить

- Переход в Анализатор, пустой вход без финансовых данных, четыре примера вопросов и поле ввода. Enter отправляет, Shift+Enter добавляет строку; Enter во время IME composition не отправляет сообщение.
- Отдельные диалоги и черновики, календарные группы истории, поиск, закрепление, переименование и удаление. Удаление диалога не меняет операции. Первый поддержанный финансовый запрос задаёт заголовок; общий контекст между диалогами не переносится.
- Демонстрационные ответы: точная сумма расходов, категории, внимание и три крупнейших расхода. Они рассчитываются из тех же 18 вымышленных операций и тем же денежным helper, что Обзор и Операции. Произвольный текст получает честное сообщение о неподключённом AI, без чтения финансовых строк или внешнего запроса.
- У каждого ответа есть период, фильтры, количество операций/счетов, сохранённый расчёт и «Как рассчитано». Предпросмотр ограничен тремя записями; кнопка открывает всю выбранную группу в Операциях с использованными фильтрами и IDs.
- В примере вопроса с сентябрём 2026 даты заменяют глобальный период, сохраняя остальные фильтры. Единственный поддержанный follow-up «А по категориям?» сохраняет scope предыдущего ответа своего диалога и заново считает текущие строки. Старый ответ остаётся снимком прежнего результата.
- На компьютере история слева; на узком экране она открывается отдельной панелью. Чат прокручивается отдельно, поле ввода внизу. Фильтры доступны в отдельном окне; закрытие возвращает фокус к вызвавшей кнопке. Светлая и тёмная тема используют прежние tokens.

## Проверки

Локально: неизменность PDF/Word и approved A/B; 10 тестов денежных primitives; strict TypeScript; 20 тестов искусственных проекций, включая шесть сценариев Анализатора; сборка Vite; 32 браузерных сценария desktop/mobile Chromium. Всего 62 теста/сценария. Браузерные сценарии проверяют историю, независимость контекста, прежние/новые суммы, дату вопроса, переход к операциям, клавиатуру, фокус, отсутствие внешних запросов/Storage, перезагрузку и горизонтальное переполнение. Уменьшение мобильного viewport проверяет доступность кнопки ввода при сокращении высоты; это не проверка настоящей клавиатуры iOS/Safari.

Визуально проверены 320/390/1024/1440 px, светлая/тёмная тема. Снимки содержат только вымышленный пример: [компьютер](../screenshots/analyzer-desktop.png), [телефон](../screenshots/analyzer-mobile.png), [ответ на компьютере](../screenshots/analyzer-answer-desktop.png), [ответ на телефоне](../screenshots/analyzer-answer-mobile.png).

GitHub повторяет проверки через существующий workflow с обычным Playwright Chromium. Результат конкретного запуска и commit фиксируются в описании PR после завершения, чтобы не менять проверяемый код только ради ссылки на CI.

## Что предстоит

Это интерфейсная демонстрация, не работающий AI. Нет провайдера/модели, Financial Relevance Gate, полного semantic context, backend Action Registry, financial mutations/Review, документов/OCR/sanitization, web/freshness, лимитов, entitlement, авторизации и постоянного хранения чатов. Остаток квоты не выдумывается. Никакие сведения о текущих курсах, ставках или тарифах не подставляются.

Ввод и история существуют только в памяти этой страницы, не передаются AI/API/web, не записываются в URL/Storage/логи. При закрытии примера история очищается; перезагрузка очищает данные и чаты. Snapshot хранит агрегаты, scope и короткий preview, а не копию всей базы. Эта локальная граница не заменяет будущий sanitizer B-09 и серверные проверки A-06.

PDF 26.2/26.3/26.5/26.6/26.9 и 47.5 отмечены partial: проверенные узкие сценарии не закрывают обязательные production требования. Все требования 1.3 остаются в силе. Следующий отдельный экран — Настройки; реальные сервисы подключаются на следующих этапах. Услуги не приобретались, Production не публиковался.
