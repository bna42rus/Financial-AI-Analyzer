# Правки экранов от 2 ноября

Согласованы владельцем в текущем задании; изменения на Staging, лимит ИИ и исходные банковские данные сохраняются.

- [x] Даты: реальные календарные значения, ошибка под полями, блокировка расчёта до исправления; отдельная ошибка обратного диапазона без общей технической ошибки/индикатора расчёта.
- [x] Общие фильтры: поиск после дат с визуальным отступом; поиск наследуется локальными условиями и передаётся всем экранам.
- [x] Несохранённое представление: справа «Сбросить», «Сохранить как новое», «Сохранить».
- [x] Все представления, включая стандартное, обычные редактируемые записи. Можно сохранить текущее, переименовать, удалить. После удаления последнего — пустое «Новое представление»; у пустого кнопка добавления базового набора виджетов.
- [x] Действия представления отдельным меню; ровные диалоги, корректные сообщения сохранения/удаления.
- [x] Итоги категоризации: обработано → с категорией → без категории → без изменений → изменено; убрать впервые/уточнено.
- [x] Настройка подписей оси графика: все либо скрыты, без автоматического пропуска части подписей.
- [x] Убрать пояснение «План и факт — отдельно для каждого бюджета».
- [x] Общий вид подтверждений: одинаковые отступы, заголовок и крестик на одной линии, нижний отступ и кнопки одной строкой, доступность на телефоне.
- [x] Настройки виджета: выделенная закреплённая шапка, единые подписи/шрифт, заметные ошибки, устойчивый выбор значений, единое выравнивание чекбоксов.
- [x] Итоги виджета столбиком, одинаковый стиль периодов/сумм, без двойного количества операций.
- [x] Временное сравнение: сопоставление интервалов по порядку, явные даты обеих сторон в графике/подсказке/таблице; отсутствие интервала не маскируется под дату другой стороны.
- [x] «Удалить виджет», «Сбросить», «По умолчанию» слева; справа копирование и применение. Сброс — к открытию окна; по умолчанию — к исходному шаблону, для нового виджета расходы по категориям.
- [ ] Проверки: только затронутые расчёты/валидация и целевые браузерные сценарии, без платных вызовов модели.

Локально: строгие типы API/Web, 30 целевых Web unit-тестов, 42 теста расчётов Обзора и сборка Web прошли. В CI добавлены проверки календарных ошибок, поиска, выбора настроек и временного сравнения на компьютере/телефоне, а также удаления последнего представления с Undo в PostgreSQL. Платных вызовов модели: 0.

Время сравнивается по порядковым интервалам (день 1, неделя 1 и т. п.). Легенда, подсказка и таблица показывают реальные даты каждой стороны. Пустой существующий интервал — 0; интервал вне выбранного периода — прочерк.
