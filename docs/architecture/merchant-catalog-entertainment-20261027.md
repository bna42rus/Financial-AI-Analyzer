## 3. Категории и правила ENT-U01–U32

### Существующее дерево, без новых категорий

| Краткое имя ниже | Путь существующего starter |
|---|---|
| Кино и мероприятия | Развлечения и хобби → Кино и мероприятия |
| Прочие развлечения | Развлечения и хобби → Прочие развлечения |
| Игры | Развлечения и хобби → Игры |
| Книги | Развлечения и хобби → Книги |
| Хобби | Развлечения и хобби → Хобби |

Предложение: билеты на спектакль/концерт/кино/цирк, обычный музейный вход/выставку/планетарный сеанс → **Кино и мероприятия**; обычные аттракционы/зоопарк/океанариум/квест/активный парк → **Прочие развлечения**; компьютерное игровое время/игры и настолки → **Игры**; книжная покупка → **Книги**; материалы творчества/моделизм/музыкальный инструмент → **Хобби**. Это экономическое назначение для установленной подходящей оплаты, не универсальная роль всех движений по бренду. Детское посещение, рабочая цель, покупка еды/одежды, обучение и прочие ветви ниже используют собственные подходящие узлы пользователя и существующие starter-категории; новые Музеи/Театр/Квесты/Настольные игры не создаются.

Для настоящей неясности — обоснованный широкий родитель/предварительная категория + видимая «Стоит проверить» с причиной. Отсутствие подробного чека само по себе не создаёт Review для ясного профиля. Нет основания даже для направления — не угадывать предмет; можно независимо сохранить установленный денежный смысл/продавца. Узкая структура личного дерева не обязательна, и широкий подходящий узел не причина Review лишь за отсутствие подкатегории.

### ENT-U01–ENT-U32

1. **ENT-U01 — Очевидный профиль.** Обычная установленная билетная покупка кино/театра/концерта/музея → Кино и мероприятия без обязательного Review за отсутствие названия спектакля/сеанса/выставки. Установленный магазин книг/хобби/игр аналогично своей ветви. Категория не user_verified и не разрешение менять остальные facets.
2. **ENT-U02 — Оператор билетов.** Афиша/Яндекс Афиша/Kassir/Ticketland/МТС Live/RedKassa/Bileter при достаточно установленной обычной досуговой билетной оплате → Кино и мероприятия. Конкретно доказанные образование/деловая конференция/услуга организатора выше общего профиля; простое слово кассир/афиша не доказательство identity.
3. **ENT-U03 — Timepad и многоцелевое событие.** Timepad обслуживает разные форматы. Известный концерт/выставка → Кино и мероприятия, известный курс → Образование, известная рабочая конференция/сервис организатора → подходящее рабочее назначение. Одного Timepad без типа события недостаточно для случайного досуга/учёбы; при обоснованной гипотезе предварительная категория + Review, иначе без предметного назначения.
4. **ENT-U04 — Площадка, организатор и платёж.** Билетный сервис, организатор, театр/арена, банк/эквайер и фактический продавец могут различаться. Не создавать второй расход из одного билета и не переименовывать банковского получателя в артиста/театр без оснований. Один бренд не гарантирует одного оператора всех франшиз/городов.
5. **ENT-U05 — Билет и самостоятельная еда.** Отдельно установленные кинобар/театральный буфет/кафе/ресторан → Еда вне дома по имеющемуся дереву, не автоматически кино. Известный магазин/книга/мерч/сувенир по предмету. Если куплен обычный билет без деталей — базовая категория без Review. Для прямо известного комбо без разбивки не выдумывать доли; обоснованное доминирующее назначение только при фактах/личном правиле, иначе родитель + Review.
6. **ENT-U06 — Офлайн и цифровой просмотр.** Кинотеатр и онлайн-подписка — разные продукты. Кинопоиск онлайн/Wink/КИОН/DIG-стриминг → Видео и музыка, установленный физический билет → Кино и мероприятия. IMAX/формат/название фильма/номер места не отдельный продавец/категория.
7. **ENT-U07 — Киносети и марки.** Синема Парк/Формула Кино — связанные марки, не разрешение объединять source/payment identities. КАРО/Киномакс/МОРИ/Мираж/Люксор/Москино/Синема 5/Иллюзион различаются по достаточному профилю. Региональные одноимённые кинотеатры не автоматически московская сеть.
8. **ENT-U08 — Театр, зал и учебное заведение.** Зрительский билет → Кино и мероприятия; оплата актёрского/музыкального обучения → соответствующее Образование/детский узел. МХТ Чехова ≠ МХАТ Горького ≠ Школа-студия МХАТ. МАМТ ≠ любой Театр Станиславского. Консерватория совмещает учебную/концертную деятельность, неизвестное назначение не угадывается по имени учреждения.
9. **ENT-U09 — Концертный абонемент.** Установленный театральный/филармонический абонемент на посещения → Кино и мероприятия, не Прочие подписки/Видео и музыка только из слова абонемент. Покупка одной программы посещений не дополнительные банковские расходы при каждом входе. Рассрочка/оплата частями по фактической финансовой роли.
10. **ENT-U10 — Музей и выставка.** Обычный установленный музейный билет/выставка/досуговая экскурсия внутри учреждения → Кино и мероприятия без лишнего Review. Наличие познавательного содержания не автоматически Образование; отдельный оплаченный курс/урок по предмету. Музейная лавка, аренда/архивная услуга и благотворительная поддержка отдельно.
11. **ENT-U11 — Бесплатная регистрация.** Бесплатное посещение/вход/резерв места/рассылка не создаёт платёж и расход. Существующее реальное банковское списание не обнуляется просто из-за бесплатной экспозиции: оно может быть другой услугой, предмет выясняется по достаточным основаниям. No-show/hold/предавторизация не обычный купленный билет автоматически.
12. **ENT-U12 — Клуб друзей и поддержка.** Доказанное пожертвование → собственная допустимая категория Благотворительность с независимой ролью; слово друг/поддержка/донат не доказывает пожертвование. Платная программа с преимуществами/билетный абонемент/магазин клуба по предмету. Посещение культуры не вывод о взглядах/вере/возрасте/диагнозе пользователя.
13. **ENT-U13 — Территория и услуга.** ВДНХ/Парк Горького/Зарядье/общий торговый променад не одна услуга и не каждый арендатор. Бесплатная прогулка не расход; известные парковка/прокат/еда/выставка/каток/обучение/магазин по соответствующему предмету и ранее согласованным разделам. Только факт места не повод произвольного досуга. Общий родитель досуга допустим, если независимо доказан досуговый платёж.
14. **ENT-U14 — Обычные аттракционы.** Установленный обычный билет в парк аттракционов/зоопарк/океанариум/СоюзМультПарк → Прочие развлечения без обязательного Review за отсутствие названия каждого аттракциона. Известный отдельно концерт/выставка/кафе/магазин/опека животного/урок выше. Вход на территорию не автоматически платный и не обязательно билет паркового оператора.
15. **ENT-U15 — Цирк и планетарий.** Установленный зрительский билет в цирк/обычный сеанс планетария → Кино и мероприятия. Цирковая/астрономическая школа или курс — по Образованию/детскому назначению при известности. Государственная карточка цирка не подтверждает полномочия продавца билетов или чужого домена.
16. **ENT-U16 — Активный парк и спорт.** FS056/057 ПандаПарк/НЕБО сохраняют обычное Прочие развлечения без Review за отсутствие деталей. Известная тренировка → Фитнес и спорт, детская секция → Кружки и секции, зрительский спортивный билет → Кино и мероприятия. Наличие спортивных услуг не переклассифицирует каждый прыжок в тренировку.
17. **ENT-U17 — Дети и цель.** Возраст/ребёнок/подарок не угадываются из возможности детских услуг. При установленной детской цели подходят собственные Прочие расходы на детей/согласованная личная категория; детский праздник и секция/учёба различаются. Кидзания/СоюзМультПарк как развлекательное посещение не автоматически учебный курс из рекламного развития.
18. **ENT-U18 — Квест.** Обычная установленная оплата развлекательного квеста/перформанса → Прочие развлечения. Онлайн-квест, корпоратив/тимбилдинг, детский праздник, сертификат и услуга организатору могут отличаться; конкретная известная цель выше. Медицинское слово клаустрофобия не diagnosis/profile продавца, каталог не каждый конечный оператор.
19. **ENT-U19 — Компьютерные клубы.** Установленное игровое время/доступ PC/консоли → Игры. Мерч/кафе/покупка оборудования/профессиональная услуга/приз/турнирная выплата не игровое время. Киберспортивная команда/логотип/франшизная плата не обычное посещение. Онлайн-покупка Steam/DIG остаётся своим продуктом, не физическим клубом.
20. **ENT-U20 — Игровое время и баланс.** Пополнение клуба/депозит, потребление часов/игровых единиц, холд и вывод не считать второй банковской покупкой автоматически. Не объявлять любое пополнение neutral без установленной модели. Отдельный подтверждённый новый банковский платёж не теряется из-за одинакового имени/суммы.
21. **ENT-U21 — Книги.** Обычный установленный книжный профиль → Книги без требования конкретного заглавия. Подписные издания — торговое имя, не автоматический recurring payment. Книжный абонемент/аудиокнига/книжная подписка по предмету чтения, не Прочие подписки только из регулярности. Конкретно известный учебный материал/кафе/игра/канцтовар выше.
22. **ENT-U22 — Республика, Москва, Библио-Глобус.** Книжная Республика ≠ FS013 Republika-фитнес/география. Магазин Москва ≠ город/банк/ТЦ/Московский Дом книги. Книжный Библио-Глобус ≠ туристический оператор; неизвестное даже направление не выбирать наугад. Формы общих имён требуют достаточного торгового контекста, но ясная категория может быть известна отдельно от точного продавца.
23. **ENT-U23 — Настольные игры.** Hobby Games/Мосигра/Игровед и установленная настолка → Игры; коллекционная миниатюра/материал/книга/игротека по известному предмету. Настольная игра не автоматически детская/учебная/подарок. Юридическая связь магазинов/издателей не делает все оплаты одним событием.
24. **ENT-U24 — Творчество и инструменты.** Обычные материалы творчества/моделизм/шитьё/музыкальный инструмент → Хобби по установленному торговому профилю. Курс, ремонт/ателье, рабочий материал, офисная канцелярия и техника по известной цели/предмету. Я-Моделист не транспорт по виду модели самолёта, Иголочка не медицинская игла, POP-MUSIC не стриминг. Узел техники MP уже согласован как проект, но здесь не создаётся.
25. **ENT-U25 — Личная, рабочая и подарочная цель.** Подтверждённое назначение/личное правило сильнее общего досугового профиля. Программа для бизнеса/корпоративное название/личная банковская карта сами по себе не доказывают рабочую цель/налоговый статус. Подарочный сертификат/групповой билет не угадывают получателя подарка, взрослого/ребёнка или доли людей.
26. **ENT-U26 — Сертификаты и комбо.** Сертификат себе/другому, абонемент, бонусные единицы, номинал/цена со скидкой, погашение и доплата имеют разные события. Не считать покупку/номинал/погашение трижды, не создавать суммы посещений из описания тарифа. Для неясной финансовой роли объяснение/Review отдельно от очевидной категории.
27. **ENT-U27 — Возврат, перенос и даты.** Отмена/перенос события не автоматический возврат денег. Дата покупки/posted/operation/дата мероприятия различаются; декабрьский спектакль, оплаченный в октябре, не переносится в декабрь сам. Подтверждённый возврат в ноябре сохраняет свой source/период и gross/net логику PDF; сервисный сбор/невозвращённая часть отдельно по известным фактам. Не давать юридической гарантии возврата из правил каталога.
28. **ENT-U28 — Части, группа и компенсация.** Подходящую расходную покупку можно распределить по пользовательским категориям/известным суммам; integer minor units, простые введённые суммы положительные, точное равенство effective сумме/валюте, максимум 50 частей по действующему контракту. Части заменяют parent в аналитике. Групповой платёж/компенсация друга не выдумывают сумму каждого/нейтральную часть; возврат в часть связывается явно, зависимость через preview. Банковские ID/даты/сумма/счёт/описание/merchant/HMAC сохраняются.
29. **ENT-U29 — Импорт и независимые покупки.** Повтор той же надёжной source-строки сохраняет ручные решения/части/provenance. Два самостоятельных равных билета/платежа не dedupe по имени/сумме/сеансу; несколько билетов в одной банковской строке не несколько source-платежей. Новое посещение не наследует случайные доли/предмет/дату прошлой покупки. Массовое историческое применение только после impact preview.
30. **ENT-U30 — Категории, приоритет и Review.** Собственные expense/both ID, доступный подходящий parent, rename/hide/delete без воскрешения/дубликатов/чужих ID. Manual facet → конкретное personal rule → широкое personal → global → AI → bank category в allowed-source границах; банковский source не меняет семантическое правило. User_verified и ручные parts защищены. Истинная неоднозначность получает разумный предварительный вариант + причину, а отсутствие детализации/leaf — не blanket Review. Категория, kind/role/link/dedupe проверяются независимо.
31. **ENT-U31 — Описание, безопасность и происхождение.** Безопасная исходная строка видна отдельно, не только Покупка; обычные ФИО/цифры/описания переводов не скрываются без основания. Принятые реквизиты/URL/обозначенные номера документов/коды авторизации скрыты; билетные QR/секрет доступа не передавать модели. Не восстанавливать скрытые ссылки/частные identity/HMAC, не копировать реальные выписки/секреты в Git/AI/logs. Ownership/статус/entitlement/RLS/deletion до preview/commit; закрытые схема/Registry/cache и evidence guard. Невалидный raw не переписывать в golden.
32. **ENT-U32 — Предел пакета и выполнение.** Все четыре пункта ENT — проект для итогового согласования. Подтверждены только оговорённые источниками профили, 761 форма ещё не наблюдённый банковский корпус. Новый раздел не внедрён, проверки NOT_RUN; старая оплата/общий разрешённый лимит не обнулены. Общий прогон/реализация после цельного согласованного каталога, истёкший admission не продлевается этим документом.

### ENT-P01–ENT-P12 — параметризация и принятие

1. **ENT-P01 — полный состав:** все ENT001–091 с own source/датой/статусом 59 SRC / 25 IDX / 7 REF; ссылки на MP/FS/DIG не независимые получатели. Достаточное подтверждение торгового профиля не подтверждение каждого юридического продавца/банковской формы.
2. **ENT-P02 — полный инвентарь строк:** все 761 кандидата плюс положительный/отрицательный/условный контекст. NFKC/casefold/ё-е по единому счётчику, не надувать case-вариантами. Для каждой формы positive/conditional/negative/blocked oracle, не массовое утверждение всех forms положительными.
3. **ENT-P03 — лексика:** начало/середина/конец безопасной строки, пунктуация/разрешённые разделители, ФИО/обычное слово/название произведения/география/код/число/чужой хвост, неправильная раскладка/визуальные гомоглифы, конфликт двух брендов и известная роль каждого.
4. **ENT-P04 — услуги:** билет/курс/конференция/аренда/кафе/мерч/книга/инструмент/активный отдых/тренировка/секция/цифровой доступ/услуга организатора; тип события, детская/подарочная/рабочая цель известны/неизвестны. Только применимые ветви, не бессмысленный Cartesian product.
5. **ENT-P05 — финансовые facets:** kind/role/category/subcategory/link/dedupe/source/confidence/verification отдельно. Purchase/refund/reversal/fee/hold/balance/transfer/payout/cashback и расход/доход/neutral/unresolved/mixed только по достаточной модели, не по марке или confidence.
6. **ENT-P06 — личное дерево/приоритет:** expense/income/both, parent без leaf, rename/hide/delete/отсутствие узла, свои/чужие IDs, protected manual/verified/parts, личное узкое/широкое правило и конфликт; global/AI/cache не перекрывают источник/ручное. Новых ENT-узлов не создавать.
7. **ENT-P07 — части:** 1/2/несколько/50/51, положительный простой ввод, signed storage и integer money, точное равенство effective/валюте, остаток/превышение/overflow; parent вместо двойного счёта, dependency conflict/refund link/Undo. Source сохраняется, сложные neutral/debt по существующему сложному контракту.
8. **ENT-P08 — lifecycle:** первый импорт/повтор/обновление/отмена/ручная правка, новая самостоятельная покупка, group payment, компенсация/сертификат/абонемент/возврат/перенос события; фактический parent/binding после провала, не эталонный. Alias не меняет собственные правила dedupe.
9. **ENT-P09 — время/валюта:** source/operation/posted/дата спектакля/период посещений различимы; зоны пользователя восточнее/западнее UTC, граница суток/месяца, несколько валют/комиссии/копейки. Не всем Москва, нет выдуманного курса/номинала/амортизации/переноса возврата к покупке.
10. **ENT-P10 — безопасные пути:** импорт, допустимые preview/commit/Undo, model/cache/closed Registry, RLS/ownership/статус/entitlement/deletion до чтения и повторно commit. Недоступный путь — BLOCKED с причиной, не PASS по похожему экрану. Только synthetic данные, не клиентские выписки/QR/секреты.
11. **ENT-P11 — экраны:** операции/карточка/поиск/фильтры продавца/категорий, обзор/графики/бюджеты/Analyzer по одной модели. Части заменяют родителя, refunds/gross/net и дата учёта едины, явный текстовый override Analyzer выше глобального контекста. Отдельные причины Review не снимаются подтверждением одной категории.
12. **ENT-P12 — воспроизводимость:** версии каталога/схемы/Registry/policy/cache, безопасный synthetic input, original raw/usage/validator/app decision, expected/actual/Review reason/фактический parent и source/parts/totals по применимости. Новый live POST и архивный replay/расход раздельно, старый общий согласованный лимит не обнулять, неопределённый отправленный запрос автоматически не повторять. Документ не запускает/не продлевает runtime admission.

Позднее для каждого случая фиксировать **PASS / FAIL / BLOCKED / NOT_RUN** и отдельно причину: источник/модель/схема/evidence/compiler/финансовая модель/UI/access/неверный oracle. Защитный отказ приложения на ошибочный ответ может быть PASS защиты и FAIL смысла модели одновременно; original raw не исправляется задним числом. Корректный ясный профиль без itemized чека — полноценный правильный результат; пустая категория не универсальная стратегия безопасности.

Приёмочная запись по применимости содержит product/merchant/agent/organizer identity, собственные category IDs/пути, kind/role/source/confidence/verification, review flag/понятную причину, суммы/валюты/даты/parts/links/totals и фактический parent. Не требовать выдуманного точного ID неприменимого/неустановленного facet.

Проверка документа сейчас ограничена уникальностью/непрерывностью 91 ENT / 32 U / 40 C / 80 T / 12 P, 761 формой и статусами, точностью ссылок/переиспользованных MP forms, форматированием и отсутствием runtime-изменений. **Ни один ENT-T в этом шаге не выполнен.** Ограниченное число будущих свежих ответов модели не доказательство точности всего каталога.
