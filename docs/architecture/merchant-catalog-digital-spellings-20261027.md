# Цифровые сервисы: написания DIG001–DIG097 — 27.10.2026

**Статус: проект второго пункта для отдельного согласования владельцем.** Состав названий и оговорки принятого списка согласованы ответом «Дальше» 27.10.2026. Здесь проработаны 97 профилей / **762 явных кандидатов** (повторы регистра/ё-е внутри профиля не увеличивают счётчик). Это не 762 проверенных банковских aliases, не измеренная точность и не выполненный модельный/продуктовый тест.

Четыре шага остаются раздельными: **названия → написания → категории/правила → будущие проверки**. Сейчас только написания и лексические ограничения; категории и план испытаний цифрового раздела не предлагаются.

## Основание и статусы

Исходные имена, ссылки и границы сохранены в [DIG001–DIG097](./merchant-catalog-digital-list-20261026.md); первичные страницы просматривались 26.10.2026. В этом шаге источники не перепроверялись заново: изменяется предложенный список строк, а не факты о доступности/названиях тарифов. **62 SRC, 32 INT, 3 PEND** сохраняют свои прежние ограничения.

- **SRC** подтверждает общий профиль, а не любое написание/оплаченность конкретной услуги.
- **INT**: регион, период, фактический платёжный продавец, условия подключения и оплаты из РФ требуют отдельной проверки; фонетика не снимает этих вопросов.
- **PEND DIG004, DIG018, DIG032** не разрешены для автоматической активации; перечень форм не закрывает отсутствующее первичное подтверждение.
- Имена продукта, платформы, компании и канала платежа не равны друг другу. Слэш в заголовке семьи не создаёт буквального alias и не разрешает считать все её продукты одной услугой/операцией. Нет новых независимых получателей сверх принятого состава.

## Общие ограничения написаний

1. Регистр не различать внутри закрытой формы: `Timeweb`, `TimeWeb`, `TIMEWEB` — один кандидат распознавания. Ё/е допустимы только внутри принятой полной строки. Исходное банковское поле и согласованное отображение в своём алфавите сохраняются; кириллическая фонетика **не заставляет** переименовывать TimeWeb в Таймвеб.
2. Варианты через `;` перечислены буквально. Повторные/технические пробелы можно нормализовать, но произвольное удаление всех пробелов/дефисов/точек, перевод названия и генерация всех транслитераций не разрешены. Слитная/раздельная/дефисная форма должна быть явно предусмотрена и затем проверена.
3. Явные падежи не дают общего стемминга. Для несклоняемых имён не выдумывать шесть падежей. «В старте», «в моём офисе», «моего склада», «звук», «огонь», «канва», «контур», «зум» могут быть обычной речью и не доказательством организации.
4. Короткие/общие слова `Pro`, `Plus`, `Premium`, `Prime`, `Cloud`, `AI`, `GPT`, `Office`, `Music`, `Play`, `Сбер`, `МТС`, `Яндекс`, `Apple`, `Google`, `VK` не определяют узкий продукт без достаточных признаков именно этого продукта. Никакого совпадения внутри номера/чужого слова или удаления чужого хвоста ради совпадения.
5. Латинские/кириллические похожие символы не подменяются глобально: MTC ↔ МТС, P7 ↔ Р7, C ↔ С, B ↔ В, O ↔ О, 0 ↔ O, 1 ↔ I. Исключение — явно перечисленные полные формы вроде 1С/1C с собственными ограничениями. Случайные смешанные письменности и неверная раскладка не генерируются автоматически.
6. Числа и обозначения продукта существенны: 360, 365, 7, 24, 1С; .ru/.to; +; VPN; Stars; Premium/Plus/Pro; Cloud/Office/Workspace. Более широкое имя в строке — только кандидат более широкого профиля, не доказательство точного платного продукта.
7. Для положительного узнавания достаточно надёжных доступных признаков торгового профиля/продукта и границ; детальный чек не обязателен для очевидного случая. Бытовая фраза, имя человека, логотип на чужом товаре, посредник или продукт внутри пакета не устанавливают прямого платёжного получателя.
8. Фонетические/раздельные/склонённые варианты ниже — предложения к проверке, **не утверждение об их встречаемости в банковской выписке**. Уверенность модели и старый cache не заменяют ограничения/первичные основания.

## Слабые сокращения, продуктовые и исторические кандидаты отдельно

Полное имя продукта сохраняет более узкую лексическую границу: КИОН Музыка не обрезается до КИОН; VK Музыка/Donut/Play/WorkSpace не обрезаются до VK; Яндекс Плюс/Музыка/Книги/360/Cloud не обрезаются до Яндекс. Google One/Workspace/AI, Microsoft 365/Xbox Game Pass, 1С/1С-Битрикс/Битрикс24, Касперский/Secure Connection и Telegram Premium/Stars также не становятся равными продуктами из-за общей части. Конфликт не решается порядком строк или числом совпавших букв: один платёж не получает две вымышленные идентичности.

- **Не безусловные положительные формы:** T Pro/Т Про, Sber/Sber Prime без достаточного профиля, МТС/MTC без продукта, Plus/Плюс, Premium, Pro, Prime, Alpha Smart, BB/WB без Клуб, Яндекс/Apple/Google/VK без сервиса. Разрешённое кириллическое «ВБ Клуб» всё равно требует конкретной торговой identity.
- **Короткие технические/доменные формы:** `Sweb`, `SBIS/Sbis`, `PS+`, `NSO`, `GPT`, `AI`, `API`, `CC`, `CDN`, `1C`, `Р7/P7`, `RU VDS`, `REG`, `.ru`, `.to`. - **Фонетика со слабой границей:** Бусты, To Do Ist, МоегоОфиса/Моего Склада, Клод, Миро, Зум, Канва, Контур, Огонь, Старт, Премьер, Звук, Джино, Тильда. Перечень не превращает имя/обычное слово в организацию, не раскрывает частных получателей.
