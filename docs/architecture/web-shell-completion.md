# Загрузка, профиль и переходы к истории

7 октября 2026 года. Завершение первой интерфейсной версии этапа 2 по принятой базе 1.3. Исходная версия — проверенный head PR №5, `672c6f63406ae61f13e68d2454ffff949e5c6a65`; main не изменяется. PDF, Word и согласованные дополнения сохранены без правок.

## Поведение

- Глобальная загрузка доступна на всех четырёх экранах, из пустого Обзора/Операций и Настроек → Загрузки. Окно принимает выбор нескольких PDF/CSV/XLSX и перетаскивание. Показывает локальные имя, размер, предполагаемый тип и состояние «Обработка пока не подключена». Пустой файл или другой тип получают отдельное объяснение. Повторные выборы остаются отдельными элементами; это не dedupe банковских операций. Можно убрать отдельный файл либо очистить выбор; закрытие очищает список.
- Содержимое файлов не читается, File objects не сохраняются в состоянии приложения, сырой документ и имя файла не отправляются. Не создаются операции или записи импорта, нет фиктивного процента прогресса/успешного импорта. После подключения настоящего pipeline обработка будет запускаться автоматически; общий ручной mapping wizard не добавлен. Описание будущего local-first процесса явно отделено от текущей функции выбора.
- Профиль содержит Account, Security, Access и Support, быструю тему и переход к privacy. Пока нет аккаунта, показаны реальные неподключённые состояния вместо выдуманных email, sessions, expiry или quota. Часовой пояс берётся из браузера и доступен только для просмотра. Тема меняет все экраны текущей страницы. Logout пока отсутствует; отдельная кнопка «Закрыть пример» действительно очищает demo, фильтры и диалоги, сохраняя оформление.
- Support позволяет подготовить/очистить локальный черновик subject/message. Закрытие окна его очищает. Отправка, адрес и attachments не подключены; сообщения другим людям не отправляются. Операции, чаты, statements и диагностика автоматически не прикладываются.
- Общая история открывается из списка Операций; из карточки открывается история явно выбранной операции. Можно снять этот scope. Сохраняются финансовые фильтры и диалоги Анализатора; Back возвращает прежний список. История остаётся пустой, потому что текущая версия не изменяет финансовые объекты. Навигация, выбор файлов и оформление не создают финансовые history events.
- Modal имеет title/description, focus trap, Escape и возврат к открывшей кнопке. При переходе к Настройкам фокус не возвращается на прежнюю кнопку поверх новой страницы. До 700 px окна занимают высоту экрана с внутренним прокручиванием. Иконка загрузки на телефоне имеет доступное имя.

## Проверки

`pnpm check`: контроль исходных документов, 10 денежных тестов, strict TypeScript, 20 Vitest-тестов и Vite build. Полный Playwright suite: 58 сценариев на desktop/mobile, из них 14 новых; всего 88 тестов и сценариев. Все прошли локально.

Новые сценарии проверяют входы в окно, focus/Escape, multiple/drop/remove/clear, пустые/другие файлы, повторный выбор, отсутствие чтения bytes/отправки/Storage, честные состояния профиля, черновик, общую/операционную историю, сохранность фильтров/диалогов и закрытие demo. Оба окна проверены на 320/390/1024/1440 px с крупным текстом и тёмной темой без горизонтального переполнения. Локально использован временный Chromium 153 вне зависимостей проекта; зависимости неизменны. В workflow добавлен запуск для PR в `feature/web-settings-recovery`, чтобы проверить эту работу до слияния PR №5. Результат GitHub CI фиксируется в PR.

## Что предстоит

Приёмка первой интерфейсной версии владельцем. Затем этап 3: заявки, verified email, ручная оплата, invitations, регистрация/login/reset, серверные ownership/entitlement, sessions и отдельная админка с TOTP/резервными кодами. Реальные account/timezone updates, Support/email, imports/parsers/sanitization/HMAC, cancellation и history/Undo относятся к следующим этапам. UI не подтверждает их реализацию.

PDF 4.7/4.8, 18.1/18.10, 33.7, 34.6 и 50.1 отмечены только partial. PDF 40.3 остаётся not_verified: отображение будущего Security не является реализацией sessions. Покупок услуг и Production release не было.
