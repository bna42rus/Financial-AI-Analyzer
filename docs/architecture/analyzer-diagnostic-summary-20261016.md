# Выводы диагностики и следующий контракт

Это обезличенная техническая сводка. Исходные model responses, частный
диагностический файл, server metadata и новые fixtures сюда не включены.
Модель, runtime, prompts, эталоны и финансовые правила не изменены.

Исходный результат остаётся 46/88. Операторское выполнение воспроизвело
весь сохранённый прогон. Подробно разобраны 42 неуспешных случая; сырые
данные остальных 46 отдельно человеком не просмотрены.

В 23 случаях JSON shape допустима. Причины отказа — evidence проверки:
12 несовпадений цитат/дублируемых period values и 11 lexical ограничений.
Эти 23 отказа не являются неверной классификацией финансовой темы.

Ручная классификация 42 неуспешных случаев:

| Наблюдение | Количество |
|---|---:|
| Верные финансовые условия, но отказ служебного evidence-контракта | 15 |
| Содержательные ошибки извлечения модели | 11 |
| Выдуманное evidence явной отмены сравнения | 2 |
| Различие financial/adjacent с прежней разметкой | 2 |
| Отсутствующая задача после отказа первого запроса | 8 |
| Неоднозначный ответ при входе без подтверждённых задач | 3 |
| Неверная связь после ошибочно принятого предыдущего запроса | 1 |

Диагностические вмешательства только в evidence дали ожидаемые outcomes
для 15 новых задач с уже верными финансовыми параметрами. Это не новая
точность модели и не production fallback. Отдельно воспроизведены три
неуспешных начала диалога, восемь отсутствующих родителей и отсутствие
подтверждённого контекста в трёх коротких продолжениях.

Ослабление всех проверок пропустит неправильные даты, формат и amount basis.
Нужны отдельные согласования: контекст, извлечение параметров, служебный
контракт и ошибки. Общие финансовые вопросы требуют своего пути ответа.

25 локальных software tests прошли, включая пять новых проверок механизмов
ошибок. Исходный executable binding сохранился; новых платных вызовов нет.

Он пока не согласован и не реализован.
