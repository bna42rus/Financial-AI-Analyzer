# Категории пользователя — предложение для согласования

Статус: НЕ СОГЛАСОВАНО; текущая реализация не изменена этим предложением.

1. Справочник определяет устойчивый смысл, например grocery, cafe, mobile, независимо от текста и структуры категорий.
2. Категория пользователя хранит связь с этим смыслом по ID; переименование её не меняет. Одну широкую пользовательскую категорию можно связать с несколькими смыслами.
3. При создании новой категории система предлагает соответствие по названию и подтверждённым пользовательским примерам. Уверенное однозначное соответствие может применяться автоматически; сомнительное показывается на проверке.
4. Удаление категории разрывает только её привязку. Классификатор повторно ищет совместимую существующую категорию, сохраняя распознанные магазин и назначение. Ручные изменения операций и личные правила имеют приоритет.
5. При отсутствии подходящей категории предлагается один раз выбрать существующую или создать новую для распознанного направления. Стандартные удалённые категории молча не восстанавливаются.

Решение владельца: принять этот порядок либо разрешить автоматическое создание недостающих направлений. Для произвольных названий без истории и без подходящих категорий достоверное автоматическое соответствие невозможно получить из одного ID.
