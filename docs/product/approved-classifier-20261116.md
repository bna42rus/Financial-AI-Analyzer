# Согласованные изменения классификатора — 16.11.2026

Владелец поручил реализовать накопленные замечания к распознаванию. Этот документ дополняет PDF v1.3 и согласованный корпус справочника. Правила финансового учёта, доступ, приватность, части, связи, владение данными и приоритет личных решений сохраняются.

## Имена и общий справочник

- У распознанного магазина/сервиса одно отображаемое имя независимо от алфавита, регистра, банковского префикса, города и идентификатора филиала. Разные компании не объединяются по одной категории.
- Кириллица или латиница выбираются для профиля один раз: ВкусВилл, Бристоль, Магнолия, Дикси, Красное & Белое, Самокат, Здрасте; Restopay и Yandex Cloud сохраняют латиницу. Ручное имя пользователя имеет приоритет.
- Разделители и технические числовые вставки могут разделять слова сервиса. Согласованные сочетания YANDEX + GO, YANDEX + OBLAKO, YANDEX + SCOOTERS распознаются при раздельном написании. Одного произвольного Yandex недостаточно для выбора услуги.
- Источник пополнений: `packages/finance-core/src/catalog/merchant-dictionary.json`. Это отдельные проверяемые данные, без исполняемых регулярных выражений. Базовые согласованные профильные документы и их типизированные ограничения продолжают действовать.
- Каждое пополнение включает одно имя, конечные кириллические/латинские написания, словоформы, целевое назначение и уверенность. Неоднозначные/противоречивые идентичности не выбираются по порядку.
- Один проверенный файл публикуется для тестового и основного окружения, без перезапуска приложения и изменения личных правил. Ошибочное обновление не заменяет действующий словарь. Будущие загрузки и явная повторная классификация используют актуальную версию.
- «МегаФон» без доказанного иного предмета получает Мобильную связь с проверкой; подтверждённый мобильный/домашний контекст уточняет назначение. Отдельно купленное оборудование не считается оплатой связи.
- «Яндекс Go» по умолчанию означает такси с пониженной уверенностью. Явный другой сервис имеет приоритет. Вендинг означает продукты с пониженной уверенностью. Поле уверенности формирует обычную рекомендацию проверки, без отдельного нового механизма предупреждений.

## Переводы себе и финансовые события

- Однозначное банковское «Перевод себе», «Между своими счетами» и перевод на собственный счёт дают own_transfer / neutral.
- Сопоставление второй стороны с уже известным собственным счётом использует полный идентификатор, HMAC с ключом пользователя и правильный тип реквизита. Последние четыре цифры карты, имя человека и сумма не доказывают владение.
- Полные реквизиты остаются локально. В запрос передаются только закрытые типизированные HMAC-свидетельства. Один и тот же владелец проверяется сервером в своём пространстве; неоднозначное совпадение не выбирается автоматически.
- При появлении нового счёта автоматические интерпретации ранее загруженных переводов пересматриваются; ручные и личные правила не переписываются.
- «Запомнить» для своего перевода создаёт личное правило по устойчивому идентификатору второй стороны для будущих входящих и исходящих переводов.
- Досрочное/частичное погашение остаётся кредитным платёжным событием. Общая сумма не объявляется процентами или основным долгом без состава платежа. При наличии собственных категорий используется Кредиты и долги / Платежи по кредитам.
- Комиссия, обслуживание и уведомления получают соответствующие собственные категории Банковских услуг. Общая кредитная плашка на обзоре удаляется; причины проверки конкретных операций сохраняются.

## Выписки и время

- Подписи, «С уважением» и прочие явно распознанные окончания таблицы не присоединяются к последней операции.
- Печатное время сохраняется и показывается для операции и проводки. Надпись UTC в строке даты убирается.
- Если часовой пояс не указан, локальное время хранится отдельно от календарной даты; неизвестный абсолютный момент и смещение не выдумываются.
- Повторное чтение тех же байтов и той же строки дополняет время/исправляет разбор без изменения transaction_id, сумм и ручных коррекций. Старые исходные наблюдения сохраняются для происхождения.
- Время, которое старый parser отбросил, и загрязнённый подписью исходный текст исправляются повторным локальным чтением исходной выписки. Банковские файлы на сервере не сохраняются.

## Требует отдельного согласования

Механизм автоматического сопоставления при полном удалении, переименовании и замене всех пользовательских категорий. До решения владельца не вводятся автоматическое создание категорий или новая обязательная форма настройки. Существующие личные привязки по ID и ручные назначения сохраняются.
