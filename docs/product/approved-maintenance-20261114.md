# Плановые технические работы — 14 ноября 2026

Согласовано владельцем: основной сайт предупреждает о плановых работах, затем показывает страницу техработ; админка остаётся доступной. Обычные обновления без перерыва не требуют техрежима.

- Админка → «Техработы»: начало/окончание МСК, заголовок и сообщение, изменение расписания, немедленный старт, отмена, ручное завершение. Команды проверяют ревизию, защищены идемпотентностью и записываются в аудит. Параллельно существует одно окно.
- Плашка появляется за 24 часа; назначенные позднее работы показываются сразу. Та же плашка повторно становится видимой за 3 часа и за час. Изменение/отмена объявления обновляет состояние открытых вкладок; отдельная рассылка писем не входит в этот объём.
- Начало определяется серверным временем. Пользовательские API закрываются с 503/MAINTENANCE, включая чтение и новые покупки. Сессии не отзываются. Health, публичный статус, выход и отдельный webhook ЮKassa доступны. Платёжные задачи продолжают принимать и учитывать оплаченные результаты.
- Импорт завершает уже начатую атомарную стадию и не начинает следующую до открытия. Оплаченные периоды, остатки, календарь обновления квот и автопродление не переписываются. Компенсации за простой требуют отдельного решения.
- Открытая вкладка без полной перезагрузки показывает страницу работ, основное приложение остаётся смонтированным; обычные диалоги временно скрываются. Поддержка продолжает работать. Шапка с логотипом, футер, контакты и юридические страницы сохраняются. При недоступном API и подтверждённых работах статический интерфейс сохраняет страницу работ; публичное последнее расписание кэшируется без персональных данных.
- Плановое окончание является ориентиром. Автоматического снятия блока по времени нет: администратор явно подтверждает готовность сервиса и завершение. На странице появляется «Вернуться в CashNeuro». При превышении срока выводится сообщение о продолжающихся работах.
- Статус проверяется раз в 30 секунд, при возвращении во вкладку и по кнопке. При блокировке пользовательского запроса статус обновляется немедленно. После недоступности API вход не сбрасывается.
- Внешнее управление Staging независимо от админки: `sudo python3 scripts/maintenance-control.py status|start|finish|cancel|extend`. Для start/extend можно передать `--until 2026-11-15T02:30:00+03:00`; start без срока задаёт ориентир на час. Скрипт строго ограничен тестовой БД localhost:5411 и пишет аудит. Если недоступна сама БД, пользовательские действия также недоступны и статическая страница остаётся открытой. Production не изменяется.

## Исправление проверки статуса

Проверка доступна через /access/maintenance — в существующей группе маршрутов API; прежний /public/maintenance остаётся совместимым на API. Ошибка проверки или неподходящий ответ не включают техрежим и не закрывают обычное приложение. Экран работ появляется только по подтверждённому активному состоянию (включая последнее подтверждённое объявление при временной потере API). Если активные работы не объявлены, недоступность API обрабатывается обычным экраном ошибки приложения, без выдуманного объявления о работах.

## Уточнения текстов и уведомлений

- Закрытие плашки запоминается в браузере между перезагрузками. Новая ревизия расписания и очередной порог предупреждения 3/1 час показываются заново. Отмена показывается один раз при первом заходе после отмены (в существующем суточном окне уведомления); после закрытия/повторного захода больше не возвращается.
- Плашка: «Сегодня с 22:19 до 23:12 по МСК сайт будет недоступен — запланированы технические работы». «Сегодня» определяется только московской датой начала; дата окончания не меняет этот выбор. Для другого дня используется «Завтра» либо дата. При переходе через полночь дата окончания уточняется в части времени окончания, начало по-прежнему обозначается «Сегодня».
- Убраны фраза «Ваши данные и история сохраняются» и её разделительная линия на странице работ. Шапка, футер, поддержка и фактическая сохранность данных не меняются.
- В админке удалены оба поясняющих абзаца, начинавшиеся «Предупреждение появляется за 24 часа…» и «Указанное окончание — ориентир…». В разделе «Техработы» уменьшены отступы между подписями/полями и строками на телефоне и компьютере. Состав настроек и поведение начала/завершения не меняются.

## Последние уточнения показа и ошибок

Предыдущее правило запоминания закрытия предупреждений заменено: предупреждение о плановых работах снова видно при новом открытии/перезагрузке сайта. Внутри сеанса закрытие действует до следующего порога 3/1 час или изменения расписания; эти напоминания появляются независимо от предыдущего закрытия. Отмена остаётся одноразовой, включая повторные заходы.

В админке ошибка поля выводится у этого поля с подсветкой и фокусом; общее сообщение при этом не дублируется. Начало в прошлом, неправильный формат дат, окончание до начала/в прошлом и ошибки длины текста имеют конкретные объяснения. Для серверных ошибок без привязки к полю остаётся общий блок с отступом 16px от кнопок. Подтверждение «Начать сейчас» не требует будущей даты начала в поле.
