# Список реализации и проверок сайта

Основа: версия 1.3. Статус на 4 октября 2026 года. Согласованные продуктовые правила сохраняются.

Этот список связывает требования с кодом и проверками. Полный реестр находится в [implementation-registry.json](implementation-registry.json); порядок работы — в [плане разработки](implementation-plan.md). Он учитывает все 55 разделов PDF, 399 нумерованных подпунктов, карту приложений, 21 согласованное изменение A/B, 10 разделов реализации C и 8 текущих решений/условий E. Часть D — исторический контекст, её противоречащие рекомендации не подменяют E.

Количество пунктов не является процентом готовности. Один пункт может содержать несколько функций и проверок. Исходный PDF и baseline остаются авторитетными; извлечённый текст в JSON — вспомогательный указатель.

## Правило готовности

- «Не проверено»: реализация и полный результат проверки отсутствуют либо ещё не подтверждены.
- «Частично»: указанный фрагмент реализован, остальные условия пункта ещё предстоят.
- «Проверено»: есть ссылки на код и результаты всех применимых проверок, включая согласованные изменения. UI-заглушка, папка или успешный узкий тест не закрывают функцию.
